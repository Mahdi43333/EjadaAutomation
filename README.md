# Java Test Automation Framework

## Overview
This project is a **simple and easy-to-use test automation framework** built in Java.  
It uses **Selenium WebDriver** for web automation, **Cucumber with Gherkin** for BDD-style tests, and **TestNG** to run the tests.  
Optionally, it can use **RestAssured** for API testing.

The framework follows **(POM)** for easy maintenance and supports **Chrome and Firefox** browsers, as well as **parallel test execution**.

---

## Features
- Cross-browser support: Chrome & Firefox (changeable from config file)
- Parallel test execution with TestNG
- Page Object Model (POM) for organized code
- BDD tests with Cucumber/Gherkin feature files
- Optional API testing with RestAssured
- Test reports using **Allure**
